# CS300 Assignment 4: My Reading List

**Name:** Kierna Marie Kearns

**Scenario:** Reading List (Books)

**Live URL:** https://kiernamarie.github.io/cs300-assignment-4/

## How to Run

- npm ci
- npm run dev
- npm test

## Description

My Reading List is a React application that allows users to organize their book collection.
Users can add and remove books, update their reading status, and filter their collection.
The application uses reusable React components and a responsive layout for desktop and mobile devices.
